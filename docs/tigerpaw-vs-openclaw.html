OpenClaw vs Tigerpaw

Agent framework comparison
Tigerpaw is a strict superset of OpenClaw

Everything OpenClaw can do, Tigerpaw can do too. Plus trading, a modern dashboard, visual automations, and email/calendar built in.

OPENCLAW
TIGERPAW
What is it
An AI agent that connects to your messaging apps. Runs bots on Telegram, Discord, WhatsApp, and 20+ other channels.
All of that, plus it can trade for you across 9 exchanges, automate tasks visually, and manage your email and calendar.
Getting Started
Edit a config file, connect channels from the terminal. Need to write code for anything beyond the basics.
One command: tigerpaw start. Config created, dashboard opens, ready to go. Point and click for everything.
Trading
Can't trade.
Trade stocks, crypto, and prediction markets from 9 exchanges. Place orders from the dashboard, your phone, or let the AI do it.
Protecting Your Money
No trading, so not applicable.
Every order checked 12 ways before it goes through. Spending limits, loss limits, and an automatic kill switch that shuts things down if something goes wrong.
The Dashboard
Older web UI. Gets the job done, but feels dated. No charts or visual data.
Modern, polished dashboard. Live charts, portfolio views, a unified message inbox, and everything in 10 languages.
Automations
You can build custom skills, but you need to write the code yourself.
Drag-and-drop workflow builder. Connect triggers to actions visually. No code needed. Templates to get started fast.
Email & Calendar
Messaging channels only. No email, calendar, or meeting integrations.
Connect Gmail, Outlook, Google Calendar, Zoom, Google Meet, Teams. Ask your AI to check your inbox or schedule a meeting.
AI Models
Works with cloud AI (OpenAI, Anthropic, Gemini). Basic local model support.
Same cloud support, plus finds local models automatically (Ollama, LM Studio). Picks the right model for each task. No API key needed for local.
Security
Basic password protection. Your keys are stored locally, but no advanced safeguards.
Encrypted credential vault, rate limiting, tamper-proof audit trail. Everything stays on your machine, locked down properly.
Your Data
Stored in scattered JSON files. Works, but hard to back up or move.
One database file. Copy it to back up everything. Credentials encrypted. Migrates from OpenClaw automatically.
Best For
People who want a lightweight messaging bot and are comfortable in the terminal.
People who want messaging, trading, and productivity all in one place, with a UI that doesn't require touching a config file.
